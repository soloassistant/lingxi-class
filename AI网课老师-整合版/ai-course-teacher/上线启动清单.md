# 上线启动清单（照着做，3 步跑起来）

> 代码层面能自动做的我都做完了。剩下 3 件事**必须有你的微信账号**，任何 AI 都替代不了。照着做，每步 2-5 分钟。

---

## 第 1 步：注册小程序并拿到 AppID（5 分钟）

1. 打开 https://mp.weixin.qq.com → 注册「小程序」账号（个人即可，免费）
2. 登录后，「开发」→「开发管理」→「开发设置」→ 找到 **AppID**
3. 复制它

## 第 2 步：开通云开发，拿到环境 ID（3 分钟）

1. 下载安装「微信开发者工具」：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 用刚才的 AppID 新建项目，导入本目录 `ai-course-teacher`
3. 工具栏点「云开发」→ 开通（免费额度够用）→ 记下 **环境 ID**（形如 `cloud1-xxxxx`）
4. 在云开发控制台创建数据库集合（首次调用云函数会自动建，建议手动建这几个）：
   - 学习数据：`progress` `wrong_books` `answer_events` `homework` `homework_reviews` `learner_prefs` `learners`
   - AI 成本与配额：`ai_quota` `ai_rate` `ai_usage_global` `ai_calls` `analytics`
     （`ai_rate` 是分钟级频控桶，R12 新增；缺了它 aiProxy 会按"计数不可用"拒绝放行 ——
      这是有意的 fail-closed，不是故障）
   - 内容与运营：`courses` `courses_draft` `posts` `reports` `teach_interrupt_logs`
   - 推送：`subscriptions` `weekly_reports`
   - `question_bank` —— **必须手动导入**，自动建出来是空集合，讲评会因此降级。
     生成与导入方式见 `tools/sync-question-bank.js` 顶部说明（导入时勾选「使用 _id」）。
   - ⚠ `checkins` 不要再建：R11 之后全仓已无写入方，学习指标改由 `answer_events` 派生。
     建了它只会让"这个集合为什么永远是空的"变成一个反复要查的问题。

## 第 3 步：填两个配置（1 分钟）

打开 `miniprogram/config.js`，替换两处：

```js
module.exports = {
  envId: 'cloud1-xxxxxxxx',          // ← 填你的环境 ID（第 2 步拿到的）
  weeklyTemplateId: 'xxxxxxxx'        // ← 可选，订阅消息模板 ID（学情周报推送用）
};
```

同时打开 `project.config.json`，把 `appid` 从 `touristappid` 改成你的真实 AppID。

---

## 部署云函数（每个函数都要）

在开发者工具左侧，`cloudfunctions` 目录下**每个函数**右键 →「上传并部署：云端安装依赖」。

重点注意 `aiProxy` 部署后，去云开发控制台 → 云函数 → `aiProxy` → 配置 → 环境变量，填入：

| 变量 | 值 |
|---|---|
| `AI_KEY_PRIMARY` | 你的大模型 API Key（在控制台填，**不要写进任何文件**） |
| `AI_BASE_URL` | 如 `https://api.deepseek.com/v1` |
| `AI_MODEL_PRIMARY` | 如 `deepseek-chat` |

（可选）`AI_KEY_SECONDARY`、`AI_MODEL_SECONDARY`、`AI_DAILY_QUOTA`、`AI_GLOBAL_QUOTA`、`AI_RATE_MAX`

---

## 学情周报推送（可选，需第 3 步的模板 ID）

1. 公众平台 → 功能 → 订阅消息 → 申请「学习报告」类模板，拿到模板 ID
2. 填入 `config.js` 的 `weeklyTemplateId`
3. 上传 `sendWeeklyReport` 时**勾选「上传触发器」**

---

## 验证

- 编译运行，能登录、能看到课程数据 → 基本 OK
- 点一个知识点 → 「AI 老师讲解」能出内容 → AI 链路 OK
- 首页进度条不再是 0 → 数据链路 OK

有任何一步报错，把报错发我。
