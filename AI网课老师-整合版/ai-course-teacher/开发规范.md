# 开发规范与约定（Development Conventions）

> 本文件是 AI 网课老师小程序的编码约定。新增代码必须遵守；存量代码已按本规范整改。
> 来源：2026-09-23 全量接线审计发现的命名不一致问题。

---

## 1. 页面路由与 query 参数（最容易出断链的地方）

**约定：页面跳转统一用 `id` 作为唯一标识参数名，页面内 `onLoad` 只读 `options.id`。**

| 页面 | 跳转写法（统一） | onLoad 读取（统一） |
|---|---|---|
| 知识点学习 teach | `/pages/teach/teach?id=<itemId>` | `options.id` |
| 课程详情 course | `/pages/course/course?id=<courseId>` | `options.id` |
| 作业讲评 homework-review | `/pages/homework-review/homework-review?itemId=<id>` | `options.itemId` |
| 协议 agreement | `/pages/agreement/agreement?type=user\|privacy` | `options.type` |

> ❌ 禁止混用 `id` / `itemId` / `courseId` 作为 query 参数名（曾导致 teach/course 页空白）。

## 2. 前端数据源

- `data/courses.js` 导出四个字段：`courses` / `chapters` / `knowledge` / `systems`。
- 知识点数组**一律用 `knowledge`**（历史名 `items` 已废弃，禁止再引用）。
- `chapter.items` 是**对象数组** `{id, title, learned, videoUrl, enBody}`，遍历时必须兼容字符串（历史数据），写法：

```js
(ch.items || []).forEach(entry => {
  const itemId = typeof entry === 'string' ? entry : entry.id;
  // ...
});
```

## 3. 云函数入参 / 出参约定

- 统一返回结构：`{ code: number, data?: any, list?: any[], msg?: string }`。
  - 列表返回 `list`（如 getWrongs/getPosts），单对象返回 `data`（如 getDashboard/getRoadmap）。
- 知识点标识入参统一用 **`itemId`**（saveWrong 兼容旧 `knowledgeId`，新代码只用 `itemId`）。
- 学习目标入参统一用 **`systemId` + `examDate`**（禁用 `system` / `targetDate`）。
- 云函数间调用统一用 `cloud.callFunction({ name: 'xxx', data: {...} })`。

## 5. AI 调用链（统一网关）

- 所有 AI 云函数（searchProxy / aiTeach / aiExplain / aiInterject / aiCourseGen / aiVariation / homeworkReview）**只通过 `aiProxy`** 调用大模型，不得自行 fetch。
- 内容安全统一通过 `secCheck`（communityPost / aiProxy 已接入）。
- AI 环境变量：`AI_KEY_PRIMARY` / `AI_KEY_SECONDARY` / `AI_BASE_URL` / `AI_MODEL_PRIMARY` / `AI_MODEL_SECONDARY` / `AI_DAILY_QUOTA` / `AI_GLOBAL_QUOTA` / `AI_RATE_MAX` / `AI_SECURITY_CHECK`。

### 密钥安全铁律（不可违反）

1. **密钥只存在于云函数环境变量**（`aiProxy` 的环境变量面板），永不写进代码、文档、注释、前端、聊天记录。
2. **前端零密钥**：小程序代码可被反编译，任何写在前端的密钥等同于公开。
3. **不提交本地配置**：`.env` / `*.local.js` / `secret.json` 已在 `.gitignore` 排除。
4. **泄露即轮换**：任何明文出现过的密钥，立即在服务商后台作废重建，而不是"藏起来继续用"。
5. **aiProxy 四层防护不得移除**：登录上下文校验 → 分钟频控 → 单用户日配额 → 全站日上限。
6. **错误信息必须泛化**：上游报错只写 `console.error` 服务端日志，返回前端只能是「AI 服务暂时不可用」。
7. 新增 AI 能力时，**不要在云函数里读密钥**，一律复用 `aiProxy`。

> 完整说明见 `ai-course-teacher/API密钥安全指南.md`；回归测试 `_test/test-ai-proxy-security.js`（25 项断言）。


## 6. 已知的坑（新代码务必避开）

1. **`chapter.items` 是对象数组**，不是字符串数组 —— 直接 `map[itemId]` 会得到 `[object Object]`。
2. **`data.knowledge`**，没有 `data.items` —— 引用会崩溃。
3. **跳转参数只用 `id`**，页面只读 `options.id`。
4. **`getDashboard` 的 `accuracy` 是 0-100 整数**，不要再乘 100。
5. **云函数列表返回 `list`**，单对象返回 `data`，前端按此读取。
