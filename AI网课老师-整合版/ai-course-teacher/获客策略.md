# 获客策略与已落地功能

> 核心判断：真人机构（学而思/新东方）最强获客手段是「免费体验 + 诊断报告」——用户花 5 分钟拿到"我什么水平、该怎么学"的专属报告，就有了"被理解"的感觉，转化率最高。本文档沉淀本产品的获客策略及对应的代码落地。

---

## 一、获客的核心逻辑

教育产品的用户决策链是：**焦虑/需求 → 想知道自己水平 → 得到个性化方案 → 信任 → 付费/留存**。

抓住这 5 个钩子，就能把"路过的人"变成"留下来的人"：

| 钩子 | 心理机制 | 对标 |
|---|---|---|
| 免费诊断 | 想知道"我到底什么水平" | 学而思入学诊断测 |
| 专属方案 | 得到"量身定制"的重视感 | 学而思个性化学习路径 |
| 可晒的成绩 | 社交认同 + 炫耀心理 | Duolingo 连续打卡截图 |
| 打卡热力图 | 沉没成本 + 视觉成就感 | GitHub 贡献图 / Duolingo |
| 分享裂变 | 好友口碑信任 | 微信生态传播 |

---

## 二、已落地（本轮代码实现）

### 1. AI 入学诊断报告（获客核心钩子）✅

`pages/quiz` 测评提交后，从"只显示分数"升级为完整诊断闭环：

- **能力雷达**：按课程维度统计正确率，视觉化展示强项/弱项
- **AI 诊断点评**：调用 `aiProxy` 生成 2-3 条具体、可执行的改进建议（鼓励语气，非空洞）
- **专属学习路径**：优先推荐薄弱课程下未学的知识点，带「待补强」标签
- **建议投入**：按得分给学习时长建议

> 这就是"5 分钟拿到量身定制的价值"，转化率最高的一步。

### 2. 分享裂变 ✅

- **测评结果分享**：`quiz` 页「分享我的成绩」按钮，标题带分数（"我在 AI 网课老师测评得了 X 分，来测测你的水平"），好友点开即进测评
- **首页分享**：`onShareAppMessage` + `onShareTimeline`（朋友圈），标题突出"7 大国际课程 + 免费 AI 一对一"
- **朋友圈分享**：支持 `onShareTimeline`，扩大传播面

### 3. 学习打卡热力图 ✅

- `getDashboard` 返回近 30 天打卡日历（`calendar` + `activeDays`）
- `report` 页渲染 GitHub 风格热力图，视觉化"坚持了多少天"
- 这是"晒图"素材 + "沉没成本"留存双重钩子

## 四、一句话策略总结

**让新用户 5 分钟内免费拿到"一份懂我的诊断报告"，让老用户有"一张值得晒的学习热力图"，让每个满意的人都成为传播节点。**

前者靠「AI 诊断报告」（已落地），中者靠「打卡热力图 + 成绩分享」（已落地），后者靠「邀请有礼 + 海报」（待做）。
